# Neovim + Zellij + iTerm2

Notes on modernising the terminal editor setup: what was wrong with the old config, what has been
changed, and what is still to do. Started 2026-10-05.

## Goal

One terminal stack that feels like a single tool:

- **iTerm2**: the terminal (fonts, Option key, clipboard)
- **Zellij**: panes, tabs, sessions and layouts
- **Neovim**: the editor, moving to [LazyVim](https://www.lazyvim.org/)

## Audit of the old Neovim config (`nvim/`)

The config in `nvim/` was generated by vim-bootstrap: Vimscript, vim-plug, 79 plugins. Its problems:

- **Four overlapping code-intelligence stacks:** coc.nvim, vim-lsp + asyncomplete, ALE, plus
  per-language plugins (jedi-vim, vim-go's gopls, phpactor, vim-racer). They produce duplicate
  diagnostics and conflicting keymaps.
- **Dead or archived plugins:** vim-racer (racer is deprecated), vim-multiple-cursors,
  vim-nerdtree-tabs, and CSApprox (does nothing once `termguicolors` is on).
- **Leader-key clashes:** `<leader>f` is mapped 3 times; `<leader>a`, `<leader>r`, `<leader>b`,
  `<leader>.` and `<leader>ee` twice each. For example, coc's code action and RunAllSpecs both
  use `<leader>a`.
- **Missing pieces:** no treesitter, no modern fuzzy picker, no Lua config.

Neovim itself is current (0.12.x), so the problem is the config, not the binary.

## Decision: LazyVim

LazyVim ships LSP, treesitter, formatting, a picker, completion, git integration and which-key
already wired up. Languages are switched on as "extras" (`:LazyExtras`), which replaces the four
stacks above with one.

Alternatives considered:

- **kickstart.nvim:** a single file you own line by line.
- **Hand-rolled on Neovim 0.12:** uses the built-in `vim.pack` plugin manager, `vim.lsp.config`
  and the built-in LSP keymaps (`grn`, `gra`, `grr`, `gri`).

### Trial side by side

`NVIM_APPNAME` picks the config directory, so LazyVim runs next to the old config without touching
it:

```sh
git clone https://github.com/LazyVim/starter ~/.config/lazyvim
NVIM_APPNAME=lazyvim nvim
```

- Old config: `~/.config/nvim`, data in `~/.local/share/nvim`
- LazyVim: `~/.config/lazyvim`, data in `~/.local/share/lazyvim`

## Done

| Change | File(s) | Notes |
|---|---|---|
| `lazygit`, `tree-sitter-cli` added to the Brewfile; `gitui` replaced by `lazygit` on Linux too | `homebrew/Brewfile`, `installer/lazygit-install.sh` (apt; latest release into `~/bin`), `installer/pacman-install.sh` | lazygit backs LazyVim's `<leader>gg` and the IDE layout, and replaces gitui as the git TUI. Current nvim-treesitter needs the `tree-sitter` CLI to build parsers |
| `EDITOR` / `VISUAL` changed from `vim` to `nvim` | `zsh/zprofile` | The `vim` → `nvim` alias only applies in interactive shells, so `EDITOR=vim` was launching the system Vim from git, Zellij and others |
| Zellij scrollback opens in Neovim | `zellij/config.kdl` (`scrollback_editor "nvim"`) | `Ctrl s` → `e` dumps the focused pane's scrollback into Neovim, where you can search, yank and save it |
| IDE layout | `zellij/layouts/ide.kdl` | Neovim (75%) above a shell (25%), with lazygit in a hidden floating pane |

### Using the IDE layout

```sh
# new session (`command` skips the `zellij -l welcome` alias in common/local_aliases)
command zellij --new-session-with-layout ide

# as a new tab inside an existing session
zellij action new-tab --layout ide
```

`Alt p` toggles the floating lazygit pane. If Neovim or lazygit exits, its pane stays open; press
`Enter` to restart it.

### Deploying Zellij changes

`~/.config/zellij` is a symlink to `~/.dotfiles/zellij`, created by `installer/linkfiles.sh`
(`make update-links`). If `~/.config/zellij` is a real directory, the script first moves it to
`~/.config/zellij.bak.<timestamp>`. Edits in the repo are live after a restart of Zellij;
check a change with:

```sh
zellij setup --check   # parses the config
```

## To do

### 1. Move between Neovim windows and Zellij panes with the same keys

Use [smart-splits.nvim](https://github.com/mrjones2014/smart-splits.nvim) in Neovim and
[vim-zellij-navigator](https://github.com/hiasr/vim-zellij-navigator) in Zellij. This keeps the
existing `Alt h/j/k/l` habit. When the focused pane runs Neovim, the Zellij plugin passes the key
through; at Neovim's edge, smart-splits hands focus back to Zellij.

Zellij (`shared_except "scroll"` block), replacing the plain `MoveFocusOrTab` binds:

```kdl
bind "Alt h" {
    MessagePlugin "https://github.com/hiasr/vim-zellij-navigator/releases/download/0.3.0/vim-zellij-navigator.wasm" {
        name "move_focus_or_tab"; payload "left"; move_mod "alt";
    };
}
// repeat for j/k/l with down/up/right
```

LazyVim (`~/.config/lazyvim/lua/plugins/smart-splits.lua`):

```lua
return {
  "mrjones2014/smart-splits.nvim",
  lazy = false,
  keys = {
    { "<A-h>", function() require("smart-splits").move_cursor_left() end },
    { "<A-j>", function() require("smart-splits").move_cursor_down() end },
    { "<A-k>", function() require("smart-splits").move_cursor_up() end },
    { "<A-l>", function() require("smart-splits").move_cursor_right() end },
  },
}
```

### 2. Stop Zellij taking Neovim's Ctrl keys

Zellij's normal mode grabs `Ctrl o/n/t/s/q/h`, which Neovim uses (jump list, completion and so on).
Pick one fix:

- **`default_mode "locked"`** (Zellij's "unlock-first" style): all Ctrl keys go to the app, and
  `Ctrl g` reaches Zellij's modes. The existing `Alt` binds live in `shared` and keep working
  while locked.
- **[zellij-autolock](https://github.com/fresh2dev/zellij-autolock):** locks Zellij automatically
  whenever Neovim (or fzf, lazygit and so on) has focus.

### 3. iTerm2 settings (manual, in the GUI)

Then export the profile into `iterm/`.

- **Profiles → Keys → Left Option key: `Esc+`.** It is currently `Meta`, which iTerm2 marks as
  deprecated; `Esc+` is the reliable choice for `Alt` bindings through Zellij.
- **Profiles → Text → Font: Hack Nerd Font Mono,** or install MesloLGM Nerd Font v3. The current
  "MesloLGM Nerd Font Complete" predates Nerd Fonts v3, so modern plugins show missing glyphs.
- **General → Selection → enable "Applications in terminal may access clipboard".** Neovim copies
  through the terminal (OSC 52), so yank works over SSH inside Zellij too.

### 4. Bring LazyVim into the dotfiles

Once the trial is settled:

1. Move `~/.config/lazyvim` into this repo (for example `nvim-lazy/`) and link it from
   `installer/linkfiles.sh`.
2. Cut over in one of two ways:
   - set `export NVIM_APPNAME=lazyvim` in `zsh/zprofile`, which makes `nvim`, `$EDITOR`, the
     Zellij scrollback editor and the IDE layout all use LazyVim; or
   - replace `~/.config/nvim` with the LazyVim config.
3. Retire `nvim/` (the vim-bootstrap config), the `update-vim-plugins` Make target and the four
   symlinks for it in `linkfiles.sh`.

## Known limitations

- **No inline images in Neovim.** Zellij doesn't pass terminal graphics through, so image previews
  won't render inside a Zellij pane.
- **Two dotfiles checkouts.** The live symlinks point to `~/.dotfiles`, while `~/code/dotfiles` is
  the working copy. Pull in `~/.dotfiles` after pushing, or the live shell config lags behind.
